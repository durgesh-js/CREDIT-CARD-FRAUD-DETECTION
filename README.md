📊 Credit Card Fraud Detection using Machine Learning

🚀 Overview

This project applies machine learning to detect fraudulent transactions in credit card data using Python and scikit-learn. It handles imbalanced data, model training, evaluation, and visualization to build a simple yet effective fraud detection pipeline.


🎯 Goals

✅ Load and explore the credit card transactions dataset
✅ Handle data imbalance using undersampling
✅ Train and evaluate models:

Logistic Regression

Random Forest


✅ Visualize confusion matrix and evaluation metrics
✅ Demonstrate a practical fraud detection workflow


🛠️ Tools & Technologies

Python

pandas, numpy (data manipulation)

scikit-learn (ML models & evaluation)

seaborn, matplotlib (visualization)

Google Colab / Jupyter Notebook



📈 Key Insights

Fraud detection requires special handling due to imbalanced datasets.

Undersampling can help create a balanced dataset for model training.

Random Forest provided higher accuracy and better performance than Logistic Regression in this scenario.

The confusion matrix clearly highlights the effectiveness in detecting fraud cases
